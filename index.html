What this demonstrates

System of recordThe shared state file is authoritative; servers do not keep their own counter copies.
ConsistencyEvery read fetches the committed shared value and its version.
Shared stateBoth server processes use the same state file.
Race conditionsSafe increments are atomic. The unsafe demo makes concurrent requests overwrite stale reads.
Multi-server behaviorOpen this page on both ports; changes appear on each as they poll the database.

The unsafe route is intentionally broken for learning. Never use that read-then-write pattern for real updates.
